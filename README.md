# UDBL L1 Android

APK Android de l'application UDBL L1.

- Version : 1.0.0 (versionCode 1)
- Identifiant Android : `com.trecie0.udblmobile`
- Fichier : `UDBL-L1-v1.0.0.apk`

Télécharger l'APK depuis ce dépôt puis l'ouvrir sur un appareil Android pour
l'installer. Android peut demander d'autoriser l'installation depuis cette
source.

Cette version est signée avec la clé de test Android. Elle convient aux tests,
mais une clé de signature dédiée est nécessaire pour distribuer les mises à
jour de façon durable.
